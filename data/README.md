# `data/` — provenance, licensing, and consent

This directory holds the **research/development** datasets used to build and
evaluate Farebi's risk-signal models. Everything here is for the offline
**factory** runtime only (`scripts/`, `harness/`, `evaluation/`). **No file in
this tree is ever read by the online serving pipeline**, and **no user upload
is ever written here** (non-negotiable #7: zero retention of submitted media).

## Layout

| Path          | Purpose                                                        |
|---------------|----------------------------------------------------------------|
| `raw/`        | Source-acquired images/video, untouched.                      |
| `interim/`    | Intermediate artefacts from the research pipeline.             |
| `processed/`  | Cleaned, normalised, feature-ready datasets.                  |
| `manifests/`  | Per-dataset manifests: source, licence, consent, row counts.  |
| `splits/`     | Identity-disjoint, source-grouped train/val/test splits.      |

## Hard rules (see `FAREBI.md` non-negotiables)

1. **Consent first.** Every `raw/` file must have a matching `manifests/`
   entry recording informed consent and the lawful basis for processing. Files
   without a manifest are **not** used.
2. **Licence must permit model training.** A dataset whose licence forbids
   derivative models is excluded from `processed/`.
3. **Identity-disjoint + source-grouped splits.** The same person, and the same
   collection source, must not appear in both train and test. This is what
   makes the evaluation honest. Generated by `scripts/make_splits.py` (later
   phase).
4. **No production PII.** Studio/celebrity/synthetic media used for attack
   simulation must not contain real identity documents.
5. **Provenance is auditable.** `manifests/` is the single source of truth for
   "where did this row come from and are we allowed to use it".

## Synthetic data is preferred

Where a signal can be developed and regression-tested on **synthetic** faces,
that is the default — it sidesteps consent entirely and keeps `raw/` small.
The test suite already uses deterministic synthetic faces (`tests/fixtures/`)
and requires no download.
